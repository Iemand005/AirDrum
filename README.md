# AirDrum

This repo contains the C++ source code for Arduino Nano and ESP32

Arduino Nano is long range Whadda server. (WPI469T)

ESP32 is Whadda receiver. (WPI469R)


## Wire arrangement

### Arduino

  All the GND to GND

  Arduino 3V3 -> + rail
  3.3V + rail -> WPI469T VCC
  3.3V + rail -> Accelerometer VCC
